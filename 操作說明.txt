倉庫物管發料 × 物料追蹤彙整－操作說明
==========================================

一、第一次使用
1. Windows 電腦先安裝 Python 3.11 或更新版本。
2. 安裝 Python 時勾選「Add Python to PATH」。
3. 解壓縮本程式包。
4. 雙擊「啟動_物料備註比對.bat」。
5. 第一次會自動安裝所需套件，完成後瀏覽器會開啟操作畫面。

二、每次比對
1. 上傳「物料追蹤彙整」CSV 或 Excel。
2. 上傳「倉庫物管發料」Excel。
3. 日期預設今天，可自行修改。
4. 建議保留：
   - 倉庫資料範圍：自動抓全部週別
   - 寫入方式：保留原缺料並追加
   - 只更新原本有缺料內容的欄位：勾選
5. 按「開始比對並產生更新檔」。
6. 檢查畫面上的更新預覽後，下載更新後 Excel。

三、比對與寫入規則
1. 優先使用「製令＋Category」精準比對。
2. 找不到精準資料時，只有該製令在最新週別僅有一筆資料，才使用製令備援比對。
3. 同一製令出現在多張週別工作表時，採用工作簿中較後面的最新週別資料。
4. 預設保留原缺料內容，下一行追加：
   【YYYY/MM/DD 倉庫更新】最新狀態
5. 重複使用同一天、同一狀態時，不會重複追加相同內容。
6. 可對應欄位：FRAME、PU、FACILITY、其他託外模組、RB、LP、AL、FFU、X-table、加工件、市購件、客供。
7. SIGNAL 與 INTERLOCK 會從「其他託外模組」中擷取同名文字。

四、輸出檔
1. 原始檔不會被修改，系統另產生新的 XLSX。
2. 更新過的儲存格以淡黃色標示。
3. 「自動比對紀錄」工作表：可追查每格原缺料、倉庫狀態、來源週別及更新後內容。
4. 「未比對清單」工作表：列出查無相同製令＋Category 的資料。

五、注意事項
1. 倉庫工作表名稱需為「0831~0904」這類四碼~四碼格式，才會列入自動週別範圍。
2. 兩份資料的製令與 Category 名稱應盡量一致。
3. 若來源欄位空白，程式不會寫入空白狀態。
4. 若只想用單一週別，可選「手動選擇週別」。
